## Data — sources
- **Primary: `GET https://api.anthropic.com/api/oauth/usage`** (`get_usage` → `parse_usage_api`). Authenticated with the Claude Code OAuth token from the macOS **Keychain** (`security find-generic-password -s "Claude Code-credentials"`; fallback `~/.claude/.credentials.json`). Returns a generic `limits[]` array — `session`, `weekly_all`, and **`weekly_scoped`** entries carrying `scope.model.display_name` (e.g. **Fable**, which has its own weekly bucket) — each with `percent`, `severity`, `resets_at` and **`is_active`** (Anthropic naming the binding window outright, so the old `max()` heuristic is only a fallback). Also returns `spend`: usage credits as **real money in the account's currency** (`amount_minor` + `currency` + `exponent`), with `enabled`/`disabled_reason`. Endpoint discovered by `strings`-ing the official `claude-code` binary (v2.1.233) — it is as undocumented as the headers. Fixture: `tests/fixtures/oauth-usage.json`.
  - **Why this replaced the header probe:** it is a **GET**, so polling no longer spends the quota it measures (the old path POSTed a real `/v1/messages` every 30s); it exposes model-scoped windows the headers never carried; and new scoped windows appear without a code change.
- **Fallback: rate-limit response headers** — if the endpoint ever disappears, `fetch_usage` falls back to the old minimal `/v1/messages` POST (`anthropic-beta: oauth-2025-04-20`, haiku, max_tokens 1) and `parse_rate_limit`, which now also reads `-7d-status`, `-representative-claim`, `grace-*`, `-surpassed-threshold` and the `overage-*` family. **Subscription auth, not API-billed.**
- **Secondary: cost (`get_cost`)** — runs `ccusage@14 blocks --active --json` → `costUSD`/`burnRate.costPerHour`/`projection.totalCost`/`models`/`tokenCounts`. Only polled while the info panel is open, on its OWN 5-min cadence (a run costs ~8-10s wall / ~7.5s CPU — it rescans the whole ~1 GB transcript archive), behind a 120s TTL cache (settings fires blocks+monthly back to back) and a 25s kill deadline (`Command::output()` has none, so a wedged child used to pin its worker AND latch the JS `busy` guard, freezing the cost figures with no error). (`costUSD` needs explicit serde `rename` — uppercase acronym.) **Pinned to `@14`**: v15+ shipped a native binary that crashed with a nix-libiconv `dyld` error here; v20 runs fine now, but `monthly` renamed the row key `month` → `period`, and our inline test fixture hides that — bump only with `#[serde(alias = "period")]` + re-captured fixtures.
- **Per-project/session breakdown (`get_sessions`)** — reads Claude Code's own JSONL transcripts directly (`sessions.rs`); see Architecture.

## Build / run
- Prereqs: **Rust** (rustup, `cargo 1.96`; non-login shells: `source "$HOME/.cargo/env"`), Xcode CLT, Node v22, ccusage reachable via `npx`.
- Dev: `npm run tauri dev` · Build: `npm run tauri build --bundles app` (→ `.app` in `src-tauri/target/release/bundle/macos/`; `bundle.targets` = app/appimage, **no `.dmg`**).
- Test: `cargo test --manifest-path src-tauri/Cargo.toml` — 34 unit tests (usage-API + rate-limit parsers, token extraction, ccusage cost/month parsers, OAuth PKCE, session aggregation) are the gate. `sessions::tests::reconcile_with_ccusage` is `#[ignore]`d: run it manually (`-- --ignored --nocapture reconcile`) after touching parsing/dedup and diff against `ccusage daily --breakdown`. **Gotcha:** a stale `target/build/tauri-*` cache can bake an old absolute path (`~/Desktop/Ton/...` from before the repo moved) → `failed to read plugin permissions`; fix with `rm -rf target/{debug,release}/build/tauri-*` (regenerates, no full clean). And `cmd | tail` masks cargo's exit code — check the real one.
- **Install / distribution**: ships as **source only** (public repo, but no installers — bundles Clawd/Anthropic assets). Users build from source: `npm install && npm run tauri build` then run the `.app` (macOS) / AppImage (Linux). **No install script** — people (rightly) don't run unknown `.sh`; the README leads with the transparent `tauri build` + an "ask your Claude Code to build it" path. `bundle.targets` = `["app","appimage"]` (no `.dmg`). CI is `.github/workflows/ci.yml` — `cargo test` gate only. Linux: macOS-only deps (`objc`, `tauri-nspanel`) are target-gated; token falls back to `~/.claude/.credentials.json`; PiP degrades to always-on-top + all-workspaces.
- Perf / leveza notes: Tauri commands are async (`spawn_blocking`) — blocking I/O on the main thread froze the UI every poll; ccusage cmd/token/HTTP-agent are cached (`OnceLock`); position saves throttled (1/s + flush on close); animations pre-rendered offscreen + JSON cached; polling decays 30s→2min when utilization is flat; **animation loop runs on `requestAnimationFrame`** (WebKit self-suspends it when the widget is occluded / off-Space / display-asleep — `setTimeout` kept waking the CPU and only paused on `document.hidden`, which a PiP window rarely is). **Memory ~150 MB is the WKWebView floor, not our content** (canvas backing stores are 20×20, DOM is tiny, no leaks) — don't chase it; idle CPU is ~0.1%. Leveza = energy, and the lever is the animation loop.
- Icon: render a Clawd frame to a 1024 PNG (PIL, see git history) → `npm run tauri icon <png>`.
- `CCUSAGE_CMD` / `CLAUDE_CODE_TOKEN` env overrides (the latter handy for headless testing without the Keychain).

### ⚠️ This dev machine's gotchas
- ~~iCloud/`~/Desktop` cwd-corruption gotcha~~ **Resolved 2026-06**: repo moved to `~/dev/Ton/claude-usage-widget`, iCloud Desktop sync off. The old `cd /`+absolute-paths workaround is no longer needed.
- **macOS PATH**: a Finder-launched `.app` only inherits `/usr/bin:/bin:...` — `usage.rs::resolve_program()`/`extra_node_dirs()` resolve `npx` to an absolute path (nvm + homebrew) so the bundled app finds node.
- **set_position is LOGICAL points**, not physical pixels — mixing physical on Retina hides the window off-screen. `lib.rs::top_right_pos` converts via `scale_factor`. Verify window placement with `CGWindowListCopyWindowInfo` (JXA): expect `X≈2264, onscreen=true`.
- First `.app` launch may prompt to allow Keychain access → **Allow**.
- **Window commands need capability permissions**: JS `setSize`/`startDragging`/`close`/etc. silently fail unless granted in `src-tauri/capabilities/default.json` — `core:default` does NOT include the mutating ones. We grant `core:window:allow-{set-size,close,start-dragging}` (always-on-top is toggled via Rust `set_always_on_top` directly, not IPC — no capability needed). (Drag and resize were both broken purely from missing perms.)
- **PiP mode** (`apply_pip` in `lib.rs`, macOS): NSWindow `collectionBehavior = CanJoinAllSpaces|FullScreenAuxiliary` (raw `objc`) + re-assert `set_always_on_top` (collectionBehavior resets the level; toggle off→on to force re-apply). **`CGWindowListCopyWindowInfo` reports `layer=0` for all-Spaces windows even though the real NSWindow `level` is 5** — don't trust CGWindowLayer here; read `[nsWindow level]` directly to verify. Also: this PiP NSPanel **doesn't show up in `CGWindowListCopyWindowInfo` by PID at all** — so I can't screenshot/locate it from the shell (Screen-Recording + Accessibility TCC are also denied). Prove the app is alive instead via its **TLS keep-alive to `api.anthropic.com:443`** (`lsof -nP -a -p <pid> -i`) = the poll loop ran = webview is up. If "not opening": likely **pin is OFF** (unpinned non-activating panel doesn't come to front → buried behind windows), not a crash.
- **Glass effect** (`set_glass`, macOS): native `NSVisualEffectMaterial::UnderWindowBackground` via `window-vibrancy` (the most translucent material — HudWindow washed the text out on a busy wallpaper; under-window read better and Ton picked it); the card CSS goes translucent (`[data-glass="on"]` → `--card-bg`/`--panel`) to reveal it. It renders dark-frosted in a dark-appearance window → white text stays legible. **The vibrancy view is a rectangle** — once the contentView is layer-backed its square corners poke out past the card's rounded corners, so we **always** clip `contentView.layer` to `cornerRadius 18 + masksToBounds` via objc — glass on *or* off (the crate's `radius` arg wasn't reliably clipped on the NSPanel). Default **off** (`cuw-glass`). For convincing glass: low card tint (~5–10%) + a specular sheen gradient in the card *background* + bright top / dark bottom inset rims — multi-factor, not just opacity. **localStorage is UTF-16LE** if you ever poke the sqlite directly (`x'3100'` = `"1"`, not `x'31'`).


## Menu bar (`tray.rs`)
The widget lives in the menu bar and has **no Dock tile**. Left click shows/hides; right click opens a menu (Show/Hide · Keep on Top · Session Breakdown · Settings · Quit).

- **Clicking the icon brings it to YOU**: the window is anchored under the icon, clamped to that icon's screen, and migrates to the Space you're on. The Space half is NOT a position problem — `set_position` cannot cross Spaces; it needs `NSWindowCollectionBehaviorMoveToActiveSpace`, which is **mutually exclusive** with the `CanJoinAllSpaces` that PiP uses, so the two are set as alternatives (`desired_pip`). Dragging it somewhere and leaving it open still wins — position only moves when asked through the icon.
- **Anchoring must adopt the position** (`adopt_current_position`), or the position watcher reads it as a system relocation and yanks the window back within a second. The first attempt at anchoring shipped without this and visibly fought itself.
- The tray icon rect is **physical**; window placement is **logical**. Same trap as `top_right_pos`.
- **`TRAY_ALIVE` gates two behaviours**: hiding on close, and dropping the Dock tile. Both are only safe once the tray actually built — otherwise a tray failure leaves no window, no tile and no icon, reachable only by Force Quit. `QUITTING` exists so the menu's own Quit isn't swallowed by the close interceptor.
- Icon is a **template image** (black + binary alpha, generated from an `idle_breathe` frame): macOS recolours it for light/dark bars and the selected state.

## Sessions window (`sessions.rs` + `src/sessions.*`)
Per-project/per-session usage, read straight from the JSONL transcripts. Correctness rules live in the module header (global dedup, no symlink following, project = git root, `cwd` isn't on line 1).

- **Named groups**: drag a project row onto a group band to file it under a client. Persisted in `groups.json` next to `window.json` — this mapping is billing input, so it must survive a reinstall and be hand-editable.
- **Share of plan** allocates a real invoice by measured share. The invoice fraction comes from a **real period** — a calendar month is one invoice, All time is the months the data spans, and a reset window uses its OWN definition (5h is 5h), never bounds echoed back from the backend. Deriving it from the requested window once allocated **689 months** ($137,944 of a $200/mo subscription) because All time starts at epoch 0.
- **Fable is excluded from the plan split** (it spends credits, not plan windows) but has no column of its own — hover any number for the per-model breakdown.
- **~API-equiv rates** default to the prices the official client states (Fable $10/$50, Opus $5/$25, Sonnet $3/$15, Haiku $1/$5) and are editable. They were once Claude 3 Opus's $15/$75, overstating the column ~3x.
- The table **revalidates**: it used to load once at boot and freeze, which is why projects looked like they'd spent zero. Now it reloads on focus when stale and shows its own age.

## Traps this codebase has already fallen into
- **`display: flex` beats `[hidden]`.** The UA rule loses to any explicit display, so `.meter[hidden]` / `.code-row[hidden]` are load-bearing — without them a hidden meter still renders.
- **Never guess window height; measure it UNSTRETCHED.** `.meters` has `flex: 1`, so measuring it rendered reports the height you HAVE, not the one you NEED — the window grew on expand and never shrank back. A transient `.measuring` class drops the flex-grow inside one frame.
- **wry implements no JavaScript panel delegates**: `prompt()` returns null and `confirm()` false, silently. Group naming was unusable until it became an inline input; destructive actions use a two-step button.
- **"Absent" and "unknown" are different.** The header fallback carries no scoped windows, and treating its empty `limits` as "none exist" erased the Fable meter on a single failed poll. `Usage.degraded` marks the degraded source so the UI keeps what it knows.
- **A number that misleads is worse than no number.** Credits render a bar only when actually spendable — the percentage is share of the spend cap, so it read as "half left" while the account was out of credits.

## Architecture
- `src/` (vanilla HTML/CSS/JS) — view state machine `compact|info|creature|settings|connect` (`data-view`), `data-state` overlays, canvas **animation engine** (palette-indexed 20×20 frames from `src/assets/animations/*.json`, **driven by `requestAnimationFrame`** with a per-frame `hold` gate; mascot **mood = burn-rate**), `setSize` on view change. Alert zones via `data-zone`; binding marker via `data-binding`; glass via `data-glass` (`--card-bg`/`--panel` translucent). Drag via `data-tauri-drag-region="deep"` (buttons block naturally; mascot canvas opts out with `="false"`). Test hooks `__cuwRender`/`__cuwRenderCost`.
